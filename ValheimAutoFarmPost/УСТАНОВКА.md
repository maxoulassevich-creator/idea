# Установка мода «Фермерский столб» (AutoFarmPost) — пошагово для новичка

Мод добавляет в игру столб, который сам собирает овощи и ягоды вокруг себя
и сам сажает семена заново. Игра: **Valheim 1.0.12** (Steam).

---

## Сразу про Thunderstore Mod Manager

Да, каталог TMM — это только чужие опубликованные моды. **Но свой мод туда поставить можно**:
в менеджере есть кнопка **Import local mod** (импорт локального мода). Плюс всегда работает
вариант «просто скопировать DLL в папку профиля». Оба способа описаны в шаге 3.

Единственное, что придётся сделать один раз руками — **собрать DLL из исходников**
(готовый файл я приложить не могу: мод компилируется вместе с файлами вашей копии игры).
Это 3 команды, ниже всё расписано.

---

## Шаг 0. Что понадобится

| Что | Где взять | Зачем |
|---|---|---|
| Valheim 1.0.12 | Steam | сама игра |
| Thunderstore Mod Manager | уже стоит у вас | профили и моды |
| .NET SDK (8 или новее) | https://dotnet.microsoft.com/download → кнопка **Download .NET SDK x64** | собрать DLL, ставится один раз |
| Папка с модом | эта папка `ValheimAutoFarmPost` | исходники и скрипт сборки |

---

## Шаг 1. Базовые моды из каталога TMM

1. Откройте **Thunderstore Mod Manager** → игра **Valheim** → выберите профиль
   (можно создать новый, например `Farm`).
2. Вкладка **Online** → найдите **BepInExPack Valheim** (автор *denikson*) → **Download**.
3. Вкладка **Online** → найдите **Jotunn** (автор *ValheimModding*) → **Download**
   (согласитесь на установку зависимостей).
4. Нажмите **Start modded** и убедитесь, что игра запускается. Выйдите из игры.

> Jotunn — обязательная библиотека: без неё столб не появится в меню строительства.

---

## Шаг 2. Собрать AutoFarmPost.dll

1. Установите **.NET SDK** по ссылке из таблицы выше (обычная установка «Далее-Далее»).
   После установки **закройте все окна терминала** и откройте новое — иначе команда `dotnet` не найдётся.
2. Положите папку мода куда-нибудь без русских букв и пробелов в пути, например `C:\Mods\ValheimAutoFarmPost`.
3. Откройте эту папку в проводнике, нажмите **правой кнопкой по пустому месту** →
   **«Открыть в терминале»** (или `Win+R` → `powershell` → `cd C:\Mods\ValheimAutoFarmPost`).
4. Выполните:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\build.ps1
   ```

   Если игра стоит не в стандартной папке Steam, укажите её явно:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\build.ps1 -ValheimPath "D:\SteamLibrary\steamapps\common\Valheim"
   ```

   > Путь к игре: Steam → правой кнопкой по Valheim → **Управление** → **Посмотреть локальные файлы**,
   > затем скопировать путь из адресной строки проводника.

5. Первый запуск скачивает пакеты — это 1–3 минуты. В конце должно появиться:

   ```
   Mod     : C:\Mods\ValheimAutoFarmPost\dist\AutoFarmPost.dll
   Package : C:\Mods\ValheimAutoFarmPost\dist\AutoFarmPost-1.0.0.zip
   Done.
   ```

## Шаг 3. Поставить мод в свой профиль

### Вариант А — через менеджер (рекомендую)

1. В Thunderstore Mod Manager выберите нужный профиль.
2. **Settings** (Настройки) → раздел **Profile** → **Import local mod**.
3. Укажите файл `dist\AutoFarmPost-1.0.0.zip`.
4. Мод появится в списке **Installed** и будет включаться/выключаться галочкой, как обычные моды.

### Вариант Б — скопировать файл руками

1. **Settings** → **Browse profile folder** (открыть папку профиля).
2. Зайдите в `BepInEx\plugins`.
3. Скопируйте туда `dist\AutoFarmPost.dll`.

Оба варианта равноценны. Если менеджер вдруг не принимает zip — используйте вариант Б.

---

## Шаг 4. Играем

Запуск только через **Start modded** в менеджере.

1. Возьмите **молоток** → вкладка **«Разное» (Misc)** → **«Фермерский столб»**.
   Нужен рядом верстак. Стоимость: **10 дерева + 5 камня**.
2. Вспашите поле **культиватором**.
3. Поставьте столб **в центр поля**.
4. Нажмите **E** на столбе — откроется сундук на 32 ячейки:

   ```
   ┌────────────────────────────────┐
   │  ряд 1  ← СЕМЕНА (8 ячеек)     │
   │  ряд 2  ← СЕМЕНА (8 ячеек)     │
   │ ─────── жёлтая линия ───────── │
   │  ряд 3  → УРОЖАЙ (8 ячеек)     │
   │  ряд 4  → УРОЖАЙ (8 ячеек)     │
   └────────────────────────────────┘
   ```

   Сверху 16 ячеек — туда кладём семена. Снизу 16 ячеек — туда падает собранное.
5. Насыпьте в верхние ряды семена (морковные, репные, луковые, ячмень, лён…).
   Столб сам засеет вспаханную землю в радиусе, а когда всё вырастет — соберёт
   урожай в нижние ряды и посадит семена заново.

Наведите прицел на столб — увидите радиусы и что он сделал в прошлом цикле.

## Шаг 5. Настройки

TMM → **Installed** → AutoFarmPost → **Config editor**
(или файл `BepInEx\config\com.oulassevich.autofarmpost.cfg` в папке профиля).

Самое нужное:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `HarvestRadius` | 8 | радиус сбора в метрах |
| `PlantRadius` | 8 | радиус посадки в метрах |
| `TickInterval` | 5 | как часто столб проверяет поле (секунды) |
| `PlantSpacing` | 1 | расстояние между посаженными растениями |
| `HarvestBerries` | true | собирать ли ягодные кусты |
| `PlantOnEmptyGround` | true | засеивать ли пустую вспаханную землю |
| `SeedRows` / `OutputRows` | 2 / 2 | сколько рядов под семена и под урожай (после смены — перезапуск игры) |

Изменения радиусов и скорости применяются сразу, перезаход в мир не нужен.

## Если что-то пошло не так

- **Столба нет в меню молотка** — проверьте, что в профиле стоят BepInEx и Jotunn
  и что игра запущена через **Start modded**.
- **Смотрим логи**: TMM → Settings → Browse profile folder → `BepInEx\LogOutput.log`.
  Ищите строки со словом `AutoFarmPost`.
- **Ничего не собирается** — столб работает только с овощами/ягодами и только пока
  рядом есть игрок (как печка или плавильня; «на расстоянии» в Valheim ничего не работает).
- **Не сажает** — семена должны лежать именно в **верхних** рядах, земля должна быть
  вспахана культиватором, и должно быть свободное место (растения не сажаются вплотную).
- **Мультиплеер** — мод должен стоять у всех игроков и на сервере, иначе к серверу не пустит.
- **Ошибка при сборке** — см. раздел «Если сборка не проходит» в `README.md`.

---

## Обновление и удаление

- Обновить: собрать заново (`build.ps1`) и повторить импорт / замену DLL.
- Удалить: снять галочку в TMM или удалить `AutoFarmPost.dll` из `BepInEx\plugins`.
  Уже построенные столбы после этого исчезнут из мира вместе с содержимым — **сначала заберите вещи**.
