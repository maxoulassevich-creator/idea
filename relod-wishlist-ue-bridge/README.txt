RELOD Wishlist × UE Woo Product Grid Bridge
===========================================
Версия 1.2.0

Что делает плагин
-----------------
1. Связывает RELOD Wishlist с Unlimited Elements Woo Product Grid через Query ID.
2. Показывает в виджете только товары из избранного.
3. Если избранное пустое, скрывает пустой грид и показывает красивую заглушку.
4. Если на странице избранного удалить последний товар, грид сразу скрывается и появляется заглушка без перезагрузки.

Как настроить страницу избранного
---------------------------------
1. Установите и активируйте этот мини-плагин.
2. Откройте страницу избранного в Elementor.
3. Добавьте виджет "Woo Product Grid".
4. В блоке Products Query:
   - Products Source: Custom Products
   - Query ID: relod_wishlist_grid
5. Включите Show Empty Message = Yes.
6. Текст Empty Message можно оставить любым — плагин всё равно заменит его красивой заглушкой.

Важно
-----
Плагин рассчитан на работу вместе с:
- WooCommerce
- Unlimited Elements for Elementor
- RELOD Wishlist

Если RELOD Wishlist отключён, список избранного будет считаться пустым.

Изменения в 1.1.0
-----------------
Исправлен баг: в обычной сетке товаров (каталог) снятие метки «избранное»
удаляло карточку товара, и вернуть её можно было только перезагрузкой страницы.

Причина
~~~~~~~
В assets/bridge.js обработчик ответа AJAX искал кнопку по селектору

    $('.woocommerce_product_grid .relod-wcwl-btn[data-product-id="…"]')

то есть во ВСЕХ гридах Unlimited Elements на странице, а не только в гриде
избранного, и делал $item.remove(). Логика, задуманная для страницы
«Избранное», срабатывала и в каталоге. То же касалось скрытия грида и показа
заглушки: они применялись к любому .woocommerce_product_grid.

Что сделано
~~~~~~~~~~~
1. PHP помечает классом relod-wl-ue-wishlist-grid только тот грид, виджет
   которого реально использовал Query ID избранного. Метка ставится в фильтре
   elementor/widget/render_content, флаг сбрасывается на
   elementor/widget/before_render_content, поэтому соседние виджеты её не
   наследуют.
2. JS работает только с помеченными гридами — и при удалении карточки, и при
   показе заглушки. В каталоге мостик теперь не вмешивается вообще.
3. Грид считается пустым, только если в нём нет ни .ue-item, ни .relod-wcwl-btn.
   Раньше проверялся лишь .ue-item, и при другой вёрстке непустой грид мог быть
   скрыт целиком.
4. Имя класса передаётся в JS через relodWishlistUEBridge.gridClass — PHP и JS
   больше не могут разойтись.

Изменения в 1.2.0
-----------------
Исправлено: грид избранного показывал не тот набор товаров, что был
в счётчике.

Причина
~~~~~~~
Страница с гридом избранного собиралась на сервере и целиком уходила
в кеш WP Rocket. Первый посетитель «фиксировал» свой список для всех
остальных: счётчик в шапке обновлялся по AJAX и был живым, а содержимое
грида приезжало из кеша — они и расходились.

Вторая причина: в post__in попадали ID товаров, которых уже нет в каталоге
(удалены, сняты с публикации). WP_Query их не находил, и карточек на
странице оказывалось меньше, чем в счётчике.

Что сделано
~~~~~~~~~~~
1. Как только виджет запрашивает товары через Query ID избранного, страница
   помечается как некешируемая: DONOTCACHEPAGE и
   do_rocket_generate_caching_files = false. WP Rocket проверяет их в момент
   сброса буфера, поэтому пометки прямо во время рендера достаточно —
   страница просто не попадёт в кеш.

2. Relod_Wishlist::get_ids() с версии 1.2.0 уже отфильтрован от несуществующих
   товаров, поэтому счётчик и грид считают одно и то же.

3. Мостик слушает событие relod_wl:changed из ядра вместо разбора тела
   запроса в jQuery.ajaxSuccess. Ядро с 1.2.0 ходит на сервер без jQuery
   (иначе «Delay JavaScript execution» в WP Rocket съедал первый клик),
   и старый способ перехвата перестал бы работать.

4. После гидрации из грида избранного убираются карточки товаров, которых
   нет в реальном списке, — страховка на случай страницы, отданной внешним
   кешем (CDN, Varnish). Чистка выполняется только если состояние
   подтверждено сервером, чтобы сетевая ошибка не опустошила грид.

Установка обновления
~~~~~~~~~~~~~~~~~~~~
Заменить папку плагина целиком. Обновлять вместе с RELOD Wishlist 1.2.0
и RELOD Wishlist Shortcodes 1.2.0.
