RELOD Wishlist
==============
Версия 1.2.0

Облегчённый вишлист для WooCommerce. Совместим с кешированием страниц
(WP Rocket, LiteSpeed Cache, WP Super Cache, W3 Total Cache).

Шорткод
-------
[relod_wishlist_page]
[relod_wishlist_page columns="4" empty_text="В избранном пока пусто."]

Хуки для сторонних шаблонов
---------------------------
do_action( 'relod_wcwl_render_ue_button', $product_id );
do_action( 'relod_ue_woo_gallery_data_attrs', $product_id, $size, $max );
Relod_Wishlist::button_html( $product_id, [ 'мои-классы' ] );

JS API
------
window.RelodWL.getIds() / getCount() / has(id) / add(id) / remove(id) / refresh()
document.addEventListener( 'relod_wl:changed', function (e) { e.detail.count } );


Изменения в 1.2.0
=================

Исправлено: счётчик расходился со страницей избранного, добавление
«не срабатывало», товары пропадали.

1. Персональные данные больше не попадают в кешируемый HTML
-----------------------------------------------------------
Раньше состояние кнопок и список ID печатались прямо в разметку через
wp_localize_script. WP Rocket клал эту разметку в кеш и отдавал всем гостям
подряд — вместе с чужим избранным.

Теперь состояние подставляет JS из некешируемого эндпоинта relod_wl_state.
Страницы каталога и товара по-прежнему кешируются целиком.

2. Операции стали идемпотентными
--------------------------------
На сервер уходит явное add/remove вместо «переверни как есть». Раньше клик
«добавить» на закешированной странице приводил к удалению товара: сервер
видел его в списке и снимал метку.

3. Запись больше не врёт про успех
----------------------------------
save_ids() возвращает bool. Раньше при отсутствии гостевой куки функция тихо
ничего не сохраняла, а AJAX всё равно отвечал success с увеличенным счётчиком.
Отсюда «count +1, а товара в избранном нет».

Гостевая кука теперь создаётся в AJAX-запросе, а не на init: на странице из
кеша PHP не выполняется, и заголовок Set-Cookie в кеш не попадает.

4. Параллельные клики не затирают друг друга
--------------------------------------------
Изменение списка идёт под блокировкой MySQL (GET_LOCK). Раньше два быстрых
клика читали одно и то же состояние, и одно из добавлений терялось.

5. Гостевые списки переехали из транзиентов в свою таблицу
----------------------------------------------------------
{prefix}relod_wishlist_guests. Транзиенты вытесняются объектным кешем
(Redis/Memcached) и стираются при сбросе кеша — избранное просто исчезало.
Старые данные мигрируют автоматически при первом чтении.
Заброшенные списки чистит ежедневный крон (90 дней, фильтр
relod_wl_guest_ttl_days). Если таблицу создать не удалось, плагин
автоматически работает на транзиентах, как раньше.

6. Протухший nonce больше не ломает запрос
------------------------------------------
Страница из кеша живёт дольше, чем nonce (12 часов). Раньше запрос умирал
с телом «-1». Теперь возвращается JSON с кодом invalid_nonce и свежим nonce,
фронт повторяет запрос один раз.

7. Скрипт не зависит от jQuery и не откладывается
-------------------------------------------------
«Delay JavaScript execution» в WP Rocket откладывал jquery-core, обработчик
клика не успевал навеситься, и первый клик пропадал. Скрипт переписан на
чистом JS, добавлен инлайн-перехватчик ранних кликов, а хендлы плагина
исключены из delay/defer/минификации WP Rocket и LiteSpeed.

8. Удалённые товары выкидываются из списка
------------------------------------------
count() считал все сохранённые ID, а WooCommerce не отдавал товары, снятые
с публикации или удалённые. Теперь список фильтруется и перезаписывается,
поэтому счётчик всегда равен числу карточек на странице.

9. Страница избранного исключается из кеша
------------------------------------------
DONOTCACHEPAGE + do_rocket_generate_caching_files выставляются во время
рендера шорткода, URI страницы дополнительно попадает в
rocket_cache_reject_uri. Если страница всё-таки пришла из кеша, JS сверяет
её со списком и перерисовывает через relod_wl_page.

Установка обновления
====================
Заменить папку плагина целиком. Таблица создастся сама, кеш страниц
сбросится автоматически. Обновлять нужно вместе с
relod-wishlist-shortcodes и relod-wishlist-ue-bridge 1.2.0.
