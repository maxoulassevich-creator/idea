Сюда build.ps1 сам копирует три файла из вашего профиля модов:

    BepInEx.dll     (из BepInEx\core)
    0Harmony.dll    (из BepInEx\core)
    Jotunn.dll      (из BepInEx\plugins\...\Jotunn)

Если скрипт их не нашёл — скопируйте эти три файла сюда вручную.
Где взять: Thunderstore Mod Manager -> Settings -> Browse profile folder.
Профиль должен быть с установленными BepInExPack Valheim и Jotunn.
