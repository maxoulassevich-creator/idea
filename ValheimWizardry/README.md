# Волшебство (Valheim Wizardry)

Мод для **Valheim 1.0.21** про волшебную палочку и стол прокачки с древом в духе Path of Exile.
На столе изучаются и совершенствуются заклинания из мира Гарри Поттера: книги, фильмы, игры, HP-вики и фанфики.

**Статус: версия 1.0.1.** Мод написан целиком: палочки, Кодекс, Древо Чар, 341 применимое заклинание, ритуалы,
великие чары, призвания, бестиарий, интерфейс. Он собирается без ошибок на эталонных библиотеках Valheim 1.0.21.
Версия 1.0.0 в игре загружалась, но падала в каждом кадре на закрытых полях игры (`FieldAccessException`). В 1.0.1 это
исправлено, а `tools/check_access.sh` проверяет, что мод не обращается к закрытым членам игры напрямую.

* Установка: [УСТАНОВКА.md](УСТАНОВКА.md)
* Изменения: [CHANGELOG.md](CHANGELOG.md)
* Код мода: [src/Wizardry/](src/Wizardry) (C#, BepInEx 5 + Jötunn 2.30.2)
* Сборка: `./build.sh` (Linux/macOS) или `build.ps1` (Windows), результат — `dist/Wizardry-1.0.1.zip`

## Как устроен код

| Файл | Что делает |
|------|-----------|
| `Plugin.cs` | точка входа: настройки, тексты, статусы, навык, патчи, регистрация предметов и Кодекса |
| `Access.cs` | доступ к закрытым членам игры: Unity 6 запрещает обращаться к ним напрямую (проверка: `tools/check_access.sh`) |
| `Generated/*.g.cs` | каталог заклинаний и Древо, собранные `tools/build_design.py` из `tools/spells` и `tools/tree_data.py` |
| `FxSpec.cs`, `SpellOps.cs` | исполняемая механика заклинаний из `tools/spell_fx.txt`: доставка (снаряд, луч, конус…) и операции |
| `Casting.cs` | панель чар, клавиши, стоимость, время каста, перезарядки, каналы, Средоточие, Тьма, ранги, навык |
| `Patterns.cs` | узоры рангов 3/6/9 |
| `Combat.cs`, `Effects.cs`, `Status.cs`, `Net.cs` | урон, статусы на владельце существа, сетевые сообщения |
| `Anchor.cs` | зоны, купола, стены, мосты, ловушки (сетевые объекты) |
| `Summons.cs`, `Polymorph.cs`, `Travel.cs`, `Reveal.cs`, `Utility.cs`, `Rituals.cs` | призывы, превращения, перемещение, корабли, погода, обнаружение, бытовые чары, ритуалы, Дары Смерти |
| `Fx.cs` | эффекты и звуки, собранные из кода, и рассылка их всем игрокам |
| `Wands.cs`, `Items.cs`, `Pieces.cs`, `Meshes.cs`, `Icons.cs`, `Loot.cs` | палочки, предметы, Кодекс с расширениями, модели, иконки, добыча |
| `Patches.cs` | крючки в игру: атака палочкой, Протего, урон, пассивные бонусы, сундуки, двери, набеги, разум существ |
| `SpellHud.cs`, `Grimoire.cs` | панель заклинаний и окно гримуара |

## Как пересобрать данные

```
python3 tools/build_design.py
python3 tools/build_preview.py
```

Скрипт читает `tools/spells/*.txt` (одна строка — одно заклинание) и `tools/tree_data.py`, а затем пишет
`design/data/*.json`, `design/02_SPELLS.md`, `design/TREE.md` и `design/VFX_TABLE.md`.
Он проверяет связность древа, ссылки «родитель → вариант» и формат строк. Второй скрипт собирает из данных
`design/tree_preview.html` по шаблону `tools/preview_template.html`.

## Источники

Список канонических заклинаний взят из выгрузки [PotterDB](https://potterdb.com) (API `/v1/spells`, 345 записей).
PotterDB собрана по [Harry Potter Wiki](https://harrypotter.fandom.com/wiki/List_of_spells).
Фанон и придуманное для мода помечены в каталоге отдельно («фанон», «мод»). Игровые эффекты везде написаны
заново под Valheim.
