# ChestSorter — сортировщик сундуков для Valheim

Раскладывает всё содержимое склада по сундукам: в одном еда, в другом металлы, в третьем
шкуры и так далее. Не хватило одного сундука — продолжает во второй, третий. После сортировки
каждый сундук подписан, и видно, что в нём лежит.

Цель — Valheim **1.0.12**, BepInEx 5. Jotunn **не нужен**, других зависимостей нет.

**Инструкция для новичка — в файле [`УСТАНОВКА.md`](УСТАНОВКА.md).**

---

## Как это работает

Три шага, между которыми вы всё контролируете:

| Клавиша | Что делает |
|---|---|
| **F8** | Показывает план в чате. Ничего не двигает. |
| **Shift + F8** | Выполняет показанный план. |
| **Ctrl + F8** | Возвращает всё ровно как было до сортировки. |

План выглядит так:

```
――― Сортировщик ―――
Сундуков: 12 · стопок сейчас: 187 · предметов: 8431
  ЕДА                    — 18/24 — 6 м на СВ
  МЕТАЛЛЫ И РУДА (1/2)   — 24/24 — 8 м на В
  МЕТАЛЛЫ И РУДА (2/2)   — 11/24 — 9 м на В
  ШКУРЫ И ТКАНЬ          — 14/24 — 4 м на Ю
  ...
Переедет стопок: 96 · объединится: 23 · станет стопок: 164
Shift+F8 — применить
```

## Главная проблема и её решение

Сундуки забиты под завязку — значит, перекладывать «по одному» некуда: нет свободной ячейки,
чтобы временно положить предмет. Поэтому мод не двигает предметы по очереди, а работает иначе:

1. **читает** содержимое всех сундуков в память;
2. **строит** полную раскладку и проверяет её;
3. **записывает** новое содержимое сразу целиком.

При этом объединение неполных стопок **никогда не увеличивает** их количество — значит,
отсортированная раскладка гарантированно помещается в те же самые сундуки. Даже если места нет
совсем и объединять нечего, сортировка всё равно возможна: это просто перестановка.

Алгоритм проверен на стенде вне игры — в том числе на худшем случае: 6 сундуков, 144 уникальных
предмета в 144 ячейках, ноль свободного места, объединять нечего. План строится, ничего не теряется.

## Что защищает содержимое

* **Предметы не копируются.** Мод перекладывает те же самые объекты предметов, а не создаёт новые:
  зачарования Epic Loot, содержимое рюкзаков Adventure Backpacks, прочность, имя мастера и качество
  переносятся нетронутыми.
* **Уникальное не объединяется.** Всё, к чему прикреплены данные (зачарованная вещь, рюкзак с
  содержимым, именная крафтовая вещь), считается уникальным и никогда не сливается с соседней стопкой.
* **Пересчёт после сортировки.** Мод считает всё содержимое до и после и сообщает, сошлось ли.
  Не сошлось — скажет об этом и предложит отменить.
* **Отмена в один шаг.** Ctrl+F8 возвращает содержимое и подписи как было.
* **План устаревает.** Если после показа плана содержимое сундуков изменилось (вы что-то взяли),
  мод откажется применять план и попросит построить заново — так исключается задвоение.
* **Сбой во время работы** — всё возвращается на место автоматически.

## Чего мод не трогает

* контейнеры, которые кто-то открыл в этот момент;
* личные (закрытые) сундуки — по умолчанию;
* всё, что не является построенным сундуком: служебные контейнеры других модов, рюкзаки,
  буферы станций (проверяется по наличию компонента постройки);
* стол зачарования и алтарь Epic Loot, корабли, повозки, сундуки с сокровищами — по списку
  исключений в настройках;
* ваш собственный инвентарь.

## Категории

| Категория | Что попадает |
|---|---|
| `FOOD` | еда и рыба |
| `POTION` | меды и зелья |
| `WEAPON` | оружие, щиты, факелы |
| `ARMOR` | броня и одежда |
| `MAGICITEM` | зачарованные вещи Epic Loot (если включено разделение) |
| `AMMO` | стрелы, дротики, снаряды |
| `TOOL` | инструменты |
| `METAL` | руда, слитки, металл |
| `WOOD` | дерево, камень, смола |
| `HIDE` | шкуры, кожа, ткань |
| `MONSTER` | части существ |
| `SEED` | семена и посадочный материал |
| `VALUABLE` | монеты, самоцветы, украшения |
| `ENCHANT` | материалы зачарования Epic Loot |
| `TROPHY` | трофеи |
| `MISC` | всё остальное |

Если сундуков меньше, чем категорий, мод сам складывает самые маленькие категории в соседние
(меды к еде, инструменты к оружию и так далее) и пишет об этом в плане.

Любой предмет можно перенаправить вручную: `Overrides = Coal=METAL, Resin=MISC`.

## Настройки

Файл `BepInEx\config\com.oulassevich.chestsorter.cfg`.

| Раздел | Параметр | По умолчанию | Описание |
|---|---|---|---|
| Keys | `PreviewKey` / `ApplyKey` / `UndoKey` | F8 / Shift+F8 / Ctrl+F8 | клавиши |
| Which chests | `Radius` | 30 | радиус сбора сундуков, м |
| Which chests | `AlsoInclude` | — | дополнительные контейнеры по имени префаба |
| Which chests | `NeverTouch` | стол зачарования, корабли, повозки… | что не трогать |
| Which chests | `SkipPersonalChests` | true | не трогать личные сундуки |
| Which chests | `SkipChestsInUse` | true | не трогать открытые сундуки |
| Which chests | `OnlyBuiltChests` | true | только построенные сундуки |
| Sorting | `SortInsideChest` | true | выравнивать порядок и внутри сундука |
| Sorting | `MergeStacks` | true | объединять неполные стопки |
| Sorting | `SeparateMagicItems` | true | отдельный сундук под зачарованные вещи |
| Sorting | `Overrides` | — | ручные исключения `Предмет=КАТЕГОРИЯ` |
| Sorting | `DisabledCategories` | — | категории, которые не нужны отдельно |
| Labels | `WriteLabels` | true | подписывать сундуки |
| Labels | `FloatingLabels` | true | подпись висит над сундуком |
| Labels | `LabelDistance` | 16 | с какого расстояния видно подпись, м |
| Labels | `LabelHeight` / `LabelSize` | 0.35 / 2.2 | высота и размер подписи |

## Подписи

Подпись хранится в самом сундуке (в его сетевых данных), поэтому переживает перезаход и видна
всем на сервере. Показывается двумя способами: текстом, висящим над сундуком, и в подсказке,
когда вы на сундук смотрите. Текст берётся у игровой таблички, так что шрифт родной.

## Как это устроено

| Файл | Ответственность |
|---|---|
| `Plugin.cs` | точка входа, горячие клавиши, порядок шагов |
| `ChestRegistry.cs`, `ChestInfo.cs` | поиск подходящих сундуков и снимок их содержимого |
| `ItemClassifier.cs`, `Categories.cs` | к какой категории относится предмет |
| `SortPlanner.cs`, `SortPlan.cs` | построение раскладки: объединение, распределение, подписи |
| `SortExecutor.cs` | применение, проверка и отмена |
| `LabelStore.cs`, `LabelVisual.cs`, `ChestLabel.cs` | подписи сундуков |
| `EpicLoot.cs` | распознавание предметов с чужими данными |
| `Wards.cs`, `Util.cs` | доступ к игре через рефлексию, чтобы не ломаться от обновлений |

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Нужен только **BepInEx** (берётся из вашего профиля модов) и .NET SDK. Из NuGet тянется один
служебный пакет для компиляции под .NET Framework.

## Ограничения

* Сортируются только загруженные сундуки: те, что рядом с вами в радиусе. Дальние области
  Valheim просто не держит в памяти.
* Отмена живёт до перезахода и отменяет только последнюю сортировку.
* Если сундуков меньше, чем видов вещей, часть сундуков станет смешанной — подпись честно
  назовёт оба вида («МЕТАЛЛЫ И РУДА + РАЗНОЕ»).
