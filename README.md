# RELOD WC Variation Media Swatches

Плагин WooCommerce: цветовые swatches для вариаций, галереи изображений и видео
для вариаций, шорткоды для страницы товара и интеграция с Woo Product Grid
(Unlimited Elements).

## Галерея товара в модальном окне

Клик по основному изображению (`[relod_main_image]`) или по любому изображению
галереи (`[relod_product_media_gallery]`, `[relod_gallery_slider]`, классическая
галерея с лентой миниатюр) открывает полноэкранную модалку.

Что умеет модалка:

- **Перелистывание** — стрелки, лента миниатюр внизу, счётчик `2 / 15`, свайп на
  тач-устройствах, клавиши `←` `→` `Home` `End`.
- **Зум** — при наведении на изображение появляется лупа; клик увеличивает
  картинку в точку под курсором. Дальше работают перетаскивание (панорама),
  колесо мыши, пинч двумя пальцами, двойной тап, клавиши `+` и `−`.
  Повторный клик или `Esc` возвращают масштаб 1:1.
- **Полноэкранный режим** — кнопка в правом верхнем углу; там, где браузер не
  даёт fullscreen для элемента (Safari на iOS), включается «театральный» режим
  без служебных элементов.
- **Клавиатура и доступность** — `role="dialog"`, `aria-modal`, ловушка фокуса,
  возврат фокуса на исходное изображение при закрытии, подписи из `i18n`.

Полный набор медиа модалка получает независимо от того, что показывает
конкретный шорткод: `[relod_product_media_gallery]` рендерится без основного
изображения, но открывается на правильном слайде — соответствие идёт по
`data-relod-media-key`, а не по порядковому номеру.

При смене вариации набор обновляется вместе с остальной страницей: AJAX-ответ
`relod_wcvms_variation_payload` возвращает поле `lightbox_items`.

### Адаптивность

| Экран | Поведение |
| --- | --- |
| Десктоп ≥ 1281px | стрелки 52px, лента миниатюр 72px |
| Ноутбук ≤ 1280px | стрелки 46px, миниатюры 64px |
| Планшет ≤ 1024px | стрелки 42px, миниатюры 58px |
| Мобильный ≤ 767px | стрелки скрыты (листаем свайпом и миниатюрами), миниатюры 52px |
| Мобильный, альбомная ≤ 480px по высоте | лента миниатюр скрыта, экономим высоту |

Учитываются `env(safe-area-inset-*)` и `prefers-reduced-motion`.

## Настройка

Параметры модалки приходят на фронт через `wp_localize_script` в объекте
`relodWcvms.lightbox`:

| Параметр | По умолчанию | Значение |
| --- | --- | --- |
| `maxZoom` | `3.5` | предельный масштаб |
| `stepZoom` | `2.2` | масштаб по клику или двойному тапу |
| `showThumbs` | `true` | лента миниатюр |

Фон и цвета переопределяются CSS-переменными на `.relod-wcvms-lb`:
`--relod-lb-bg`, `--relod-lb-ink`, `--relod-lb-pad`, `--relod-lb-thumb-h`,
`--relod-lb-nav`.

## Установка

Каталог `relod-wc-variation-media-swatches/` копируется в `wp-content/plugins/`.
Требования: WordPress 6.4+, PHP 7.4+, WooCommerce 8.5+.
